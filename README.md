# Kanban Board – School Group Project

This Kanban Board is a web-based task management application developed as part of a school group project. It helps users organize, manage, and track tasks through a visual workflow.
The board categorizes tasks into different stages, such as **To Do**, **In Progress**, and **Done**, allowing users to monitor task progress and manage their work more efficiently.

## Features
- Organize tasks using a Kanban board.
- Track task progress across different workflow stages.
- Manage tasks in a structured and visual way.
- Improve task organization and workflow management.


## Purpose
This project was developed to apply our programming knowledge, improve teamwork and collaboration, and gain practical experience in building a web-based application.
