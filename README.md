# Kanban Board Project

This Kanban Board is a web-based task management application developed as part of a school group project. It helps users organize, manage, and track tasks through a visual workflow.
The board categorizes tasks into different stages, such as **To Do**, **In Progress**, and **Done**, allowing users to monitor task progress and manage their work more efficiently.

## Purpose

This project is to apply our programming knowledge, improve teamwork and collaboration, and gain practical experience in developing a web-based application.
Through this project, we had the opportunity to strengthen our **Laravel** development skills, practice problem-solving, and collaborate with team members to build a functional application.

## Project Type

School Group Project
